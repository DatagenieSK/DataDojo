# Welcome to DataDojo 🥋

Welcome to the dojo! Here, you learn Python and data analysis step by step through short, playful katas.

No setup. No installations. No passwords. Python runs directly inside your web browser.

## 🥋 The Dojo Belt System

In martial arts, you start as a beginner with a White Belt and progress one technique at a time. In DataDojo, each belt teaches one core data skill:

| Belt | Name | What You Learn | Status |
| :--- | :--- | :--- | :--- |
| ⚪ **White** | **Start Here** | First lines of code, variables, and friendly feedback | **Active Now** |
| 🟡 **Yellow** | **Python Basics** | Conditions, loops, and custom functions | Coming soon |
| 🟠 **Orange** | **NumPy** | Working with grids and lists of numbers | Coming soon |
| 🟢 **Green** | **pandas** | Tables, spreadsheets, and data cleaning | Coming soon |
| 🔵 **Blue** | **Visualization** | Charts, bar plots, and storytelling | Coming soon |
| 🟣 **Purple** | **Stats** | Averages, spread, and finding signals | Coming soon |
| 🟤 **Brown** | **Intro ML** | Patterns, predictions, and models | Coming soon |
| ⚫ **Black** | **Capstone** | Complete real-world data project | Coming soon |
