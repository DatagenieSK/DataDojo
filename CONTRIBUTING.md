# Contributing to DataDojo 🥋

Thank you for helping teach beginners to code!

## How to Contribute Katas
1. Read the [Kata Authoring Guide](docs/contribute/writing-a-kata.md).
2. Choose an unassigned topic or propose one in an issue.
3. Keep the reading level around Grade 7.
4. Include exactly 3 Sensei Tips per exercise.
5. Test your kata locally with `python tools/validate_katas.py`.
6. Test your draft with a real beginner who has never coded before!

## Submitting Pull Requests
- Keep changes focused and atomic.
- Verify that `mkdocs build --strict`, `node --test`, and `python tools/validate_katas.py` all pass before opening a PR.
